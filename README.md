# hBN-Bilayer-TB-Parameters

This repository hosts a high-fidelity, 16-band tight-binding (TB) model for AA', AB1', and AB -stacked bilayer hexagonal Boron Nitride (hBN). The parameters were derived from first-principles Density Functional Theory (DFT) calculations using the Wannierization process (GPAW/ASE/Wannier90).]

The model is specifically designed to investigate the Stark effect and electronic state localization under external vertical electric fields, supporting large-scale simulations  that are computationally prohibitive for standard DFT.
